## what is it?

Pygame is an advanture terminal game. The user types a number, hits enter, and the story actually goes somewhere else because of that.
It starts with an old watch on the sidewalk. The hands are going backwards, and the user ends up in 1998. There's a kid named Harry, and the user has to figure out what happened and how to get back. There are a few endings. They depend on what gets picked.

## why it exist?

I found my notebook from 3 years ago and it was full of stories like this, and I decided to choose one and build a terminal game for it. Almost all of the phrasing from the notebook was kept here in the same way. I had to fix a few things that weren't phrased well, but I tried to stick as closely as possible to the wording written in the notebook.
